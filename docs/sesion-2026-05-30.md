### Imágenes PNG/WebP por categoría

**BD:** `ALTER TABLE categorias ADD COLUMN imagen_url TEXT;`

**Storage:** bucket `categorias` (público) con políticas:
```sql
CREATE POLICY "categorias_insert" ON storage.objects FOR INSERT TO authenticated
  WITH CHECK (bucket_id = 'categorias');
CREATE POLICY "categorias_update" ON storage.objects FOR UPDATE TO authenticated
  USING (bucket_id = 'categorias');
CREATE POLICY "categorias_select" ON storage.objects FOR SELECT TO public
  USING (bucket_id = 'categorias');
```

**Comportamiento:**
- En el admin, cada fila tiene un cuadro de imagen (antes del emoji). Click → upload → thumbnail actualizado. El guardado final persiste la URL junto con el resto de los campos.
- Hover sobre el thumbnail → preview ampliado (`160×160px`) flotante via `createPortal` (evita el `overflow-hidden` del contenedor padre)
- Emoji picker **eliminado** de la UI — las categorías usan imagen o placeholder SVG gris
- Categorías sin imagen muestran un placeholder SVG gris en todos los lugares donde se muestran

**`src/lib/types.ts`:** `imagen_url: string | null` agregado a `Categoria` y a `TecnicoDisplay`; `toSlug` ahora es exportada

**Actualización de display en:**
- `src/pages/index.astro` — grilla de categorías populares usa imagen o placeholder
- `src/components/FiltroTecnicos.tsx` — botones de filtro muestran imagen de la categoría
- `src/components/FormSolicitud.tsx` — selector de categoría visual (tarjetas con imagen)

**`src/pages/tecnicos/index.astro`:** fetchea categorías desde BD y las pasa a `FiltroTecnicos`

### Flujo admin asigna técnico (ítem 8)

**Objetivo:** el cliente solicita un servicio sin elegir técnico; el admin asigna.

**BD:**

**`src/pages/api/crear-solicitud.ts`:** `tecnicoId` ahora es opcional (puede ser `null`)

**`src/pages/solicitud.astro`:** refactorizado para dos modos:
- Con `?tecnico=ID` → flujo original desde perfil del técnico (sin cambios)
- Sin param (o con `?categoria=ID`) → carga todas las categorías activas, sin técnico pre-seleccionado

**`src/components/FormSolicitud.tsx`:**

**`src/components/Navbar.tsx`:**
- Clientes y usuarios anónimos ven **"Solicitar servicio"** → `/solicitud`

**`src/pages/index.astro`:**

**`src/pages/tecnicos/[id].astro`:** botón "Solicitar servicio" eliminado del perfil del técnico

**`src/pages/dashboard/admin.astro`:**
